# Пакетное пополнение периода: инструкция для модели

Ты дописываешь материалы в один период базы. Большие файлы периодов не читай: всё, что нужно, есть здесь и в сводке.

1. `pnpm -s content:brief <период> --persons` — что уже есть: события, персоналии, термины, культура, тесты.
   Персоналии других периодов там тоже есть, на них можно ссылаться. Существующее не дублируй.
2. Напиши **один** новый файл `content/packs/osnova/data/<номер>-<период>-plus.json` целиком, одной записью,
   а не по кусочку. Формат файла: `{ "events": […], "persons": […], "terms": […], "culture": […], "links": […], "quizzes": […] }`.
3. `pnpm -s content:check --file <твой файл>` — исправь каждую ✖ и ⚠. Остальные файлы не трогай.
   Сливать файл с файлом периода не нужно: это потом сделает `pnpm content:merge`.

## Правила

- Только твёрдо установленные факты из учебников и энциклопедий. Если сомневаешься в детали, не пиши её.
- Даты до 1918 года — по старому стилю. `month` и `day` ставь, только если уверен.
- Всё по-русски, без латиницы. Стиль — как у статьи в энциклопедии для старшеклассника.
- id: `e-` событие, `p-` персона, `t-` термин, `c-` культура, `q-` тест, дальше транслит через дефис. Пример: `pnpm -s content:id event "Название"`.
- `importance`: 3 — обязательно знать, 2 — важно, 1 — деталь для финала олимпиады.
- `wiki` — точное название статьи русской Википедии. По нему CI найдёт фото: портрет, картину, место.
  У персоналий формат «Фамилия, Имя Отчество».
- Персоналиям не пиши `reigns`: правители уже все есть. Добавляй только людей, чья главная деятельность пришлась на твой период.
- Связи `links`: `cause` (from привело к to), `part-of` (from — часть to), `participant`/`leader` (персона → событие),
  `author` (персона → произведение), `influence`, `ally`, `opponent`, `related`. Противник — только реальный враг или соперник.

## Тест

Один тест на 12 вопросов олимпиадного уровня, по новым и старым материалам периода:
`{"id": "q-<период>-olimp", "title": "<Период>: олимпиадный уровень", "period": "<период>", "level": "region", "questions": [...]}`.
Смешай типы вопросов, у каждого есть `prompt` и `explain` с объяснением:

- `single`: `options` и `answer` (индекс с 0);
- `multiple`: `options` и `answers`;
- `order`: `items` в правильном порядке;
- `match`: `pairs` [[a, b]];
- `year`: `answer` — год;
- `text`: `answers` — все допустимые формы;
- `hints`: `hints` и `answers`, «Кто я?»;
- `errors`: `segments` [{text, wrong?, fix?}];
- `open` — развёрнутый ответ: `answer` (эталонный ответ, 3–6 предложений) и `criteria` (3–6 пунктов, что должно быть в ответе: «Названа причина: …», «Указан год …», «Дана оценка …»);
- у любого вопроса может быть `excerpt` — короткий отрывок источника, по которому надо узнать событие или человека.
