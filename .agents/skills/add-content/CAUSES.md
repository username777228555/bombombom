# Причины и следствия: инструкция для модели

Связи `cause` («A привело к B») питают вопросы на анализ: «Назовите причины…», «Каковы последствия…», «Почему?».
Сейчас у большинства событий причины в графе не указаны. Ты достраиваешь их для одного периода.

1. `pnpm -s content:brief <период> --causes --persons` — события периода с важностью и числом известных причин (←N) и следствий (→N),
   а также события и персоналии соседних периодов (в разделе персоналий; события соседних периодов смотри через
   `pnpm -s content:brief <соседний период> --causes`).
2. Напиши файл `content/packs/osnova/data/<номер>-<период>-plus.json`: `{ "links": [ … ] }`.
3. `pnpm -s content:check --file <файл>` — исправь каждую ✖ и ⚠.

## Правила

- Для каждого события с важностью 3 и 2, у которого ←0 или ←1, добавь 1–3 причины, если они твёрдо известны из учебников.
  Причина — **другое событие базы** (id из сводки, можно из предыдущего периода), а не абстракция.
- Так же добавь следствия событиям с →0, если следствие есть в базе.
- `{"from": "e-причина", "to": "e-следствие", "type": "cause"}`; можно `"label"` — 2–5 слов, как именно («поражение показало отсталость»).
- Не связывай просто соседние по времени события. Не дублируй уже существующие связи. Только реальные id из сводки.
- 30–60 связей на период.
