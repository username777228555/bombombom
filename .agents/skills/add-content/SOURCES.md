# Хрестоматия: инструкция для модели

На олимпиадах в каждом варианте есть работа с источником: узнать документ по отрывку, назвать автора, год,
событие, объяснить содержание. Ты пишешь для периода отрывки ключевых исторических источников.

1. `pnpm -s content:brief <период> --persons` — что уже есть в периоде (события и персоналии для ссылок).
2. Напиши **один** файл `content/packs/osnova/data/<номер>-<период>-plus.json` целиком:
   `{ "sources": [ … ], "links": [ … ] }`.
3. `pnpm -s content:check --file <файл>` — исправь каждую ✖ и ⚠.

## Какие источники

20–25 на период: летописи и жития, законы и судебники, грамоты, указы и манифесты, договоры, речи и письма,
публицистика, мемуары, документы партий и государства. Те, что спрашивают на олимпиадах и есть в школьных хрестоматиях.

## Правила честности

- `excerpt` — **подлинный** текст источника, 1–4 предложения (до 600 знаков), в той орфографии, в какой его печатают в хрестоматиях
  (древнерусские тексты — в переводе или в привычном школьном виде). Бери только отрывки, которые точно помнишь дословно.
- Если дословно не помнишь, но содержание знаешь твёрдо: пиши близкий к тексту пересказ, начни его с «(Пересказ)»
  и поставь `"confidence": "medium"`. Не выдумывай цитат.
- Поле `note` **не используй** (оно занято под имена файлов книг).
- В тексте отрывка не должно быть названия документа и имени автора: по нему ученик должен их узнать.

## Формат

```json
{"id": "s-sobornoe-ulozhenie-1649", "title": "Соборное уложение", "kind": "law", "period": "c17", "year": 1649,
 "author": "p-aleksey-mikhaylovich", "authorName": "Земский собор при царе Алексее Михайловиче",
 "excerpt": "А которые… (подлинный отрывок)",
 "clues": ["3–4 подсказки от трудной к лёгкой: обстоятельства принятия, ключевые слова, последствия — без названия"]}
```

`kind`: chronicle, law, letter, memoir, decree, treaty, speech, literature (только художественная публицистика вроде
«Путешествия из Петербурга в Москву»), document, press. `author` — id персоналии из сводки, если автор есть в базе.

Связи: для каждого источника 1–2 связи `{"from": "s-…", "to": "e-…", "type": "related"}` с событием, к которому он относится,
и `{"from": "p-…", "to": "s-…", "type": "author"}`, если автор в базе. Всё по-русски.
