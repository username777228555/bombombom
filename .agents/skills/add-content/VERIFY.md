# Проверка новых материалов: инструкция для модели

Другая модель написала файлы `content/packs/osnova/data/*-plus*.json`. Ты редактор-фактчекер: ученик будет учить это
к олимпиаде, поэтому одна неверная дата хуже десяти пропущенных событий.

1. Прочитай назначенные тебе файлы целиком.
2. Для каждой записи проверь по памяти о надёжных источниках (учебники, энциклопедии):
   - год, `endYear`, `month`/`day` (до 1918 года — старый стиль), годы жизни персоналий;
   - имена, должности, числа, названия, места; кто в чём участвовал (`persons`, связи `participant`/`leader`/`author`);
   - связи `cause`: действительно ли A привело к B;
   - `importance`: 3 — только для того, что знает каждый выпускник;
   - отрывки источников: подлинный ли текст; если сомнительно — пометка «(Пересказ)» и `"confidence": "medium"`.
3. Исправь ошибки прямо в файле правкой. Деталь, в которой не уверен и которую нельзя проверить, удали (поле `day`,
   спорную фразу), а запись оставь. Запись целиком удаляй, только если событие выдумано или дублирует уже существующее
   (`pnpm -s content:brief <период>` покажет, что уже есть в базе), и тогда убери и её связи.
4. `pnpm -s content:check --file <файл>` — без ✖ и ⚠.

Не трогай другие файлы, git не запускай. В ответе — список правок: запись, что было, что стало.
