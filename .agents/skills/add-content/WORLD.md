# Всемирная история для синхронизации: инструкция для модели

Олимпиады спрашивают: «Какое событие всемирной истории произошло в те же годы, что и…», «в правление…»,
«расположите события России и мира по порядку». Для этого в базе есть события с `"scope": "world"`:
они видны отдельной полосой на ленте времени и питают вопросы на синхронизацию. Файл — `content/packs/osnova/data/15-vsemirnaya.json`.

1. Что уже есть: `grep -h '"scope": "world"' -B12 content/packs/osnova/data/*.json | grep '"title"'` — не дублируй.
2. Запиши события в файл `{ "events": [ … ] }` (если файл уже есть — дописывай в него).
3. `pnpm -s content:check --file content/packs/osnova/data/15-vsemirnaya.json` — исправь каждую ✖ и ⚠.

## Правила

- Только события, которые знает школьный курс всеобщей истории и которые годятся как ориентиры: войны, революции,
  открытия, договоры, основание государств, религиозные и научные перевороты. Не мелочи.
- Поля: `id` (`e-` + транслит), `title`, `year` (`endYear` для долгих), `period` — **российский период по году**
  (`ancient` 800–1132, `udel` 1132–1462, `muscovy` 1462–1598, `c17` 1598–1689, `c18` 1689–1801, `c19` 1801–1894,
  `revolution` 1894–1922, `interwar` 1922–1941, `war` 1941–1945, `late-ussr` 1945–1991, `modern` 1991–…),
  `"scope": "world"`, `tags` (`foreign`, `war`, `politics`, `science`, `church`, `culture`, `economy`…),
  `importance` (3 — самые известные даты, остальные 2), `summary` (2 предложения), `wiki` (статья русской Википедии).
- Даты — по новому стилю (это всемирная история), `month`/`day` — только если уверен.
- Название без года и без слова «год»: «Великая хартия вольностей», «Начало Тридцатилетней войны».
- Связи не обязательны. Если событие прямо касается России, добавь `links` (`related` или `cause`) с id из базы.
- Равномерно по эпохам: от 800 года до наших дней, в каждом российском периоде не меньше 8 событий.
