# Книги для приложения

Приложение («Библиотека → Скачать с GitHub») берёт книги отсюда и из релиза `books`.

- **До 25 МБ** — сюда: «Add file → Upload files».
- **Больше 25 МБ** (до 2 ГБ) — в релиз: «Releases → Draft a new release» → «Choose a tag»: впишите `books`,
  «Create new tag» → перетащите файлы в «Attach binaries» → «Publish release». Новые книги добавляйте в тот же
  релиз: «Releases → books → Edit». Такие книги скачиваются в приложении на телефоне.

Имена файлов лучше не менять: по ним приложение узнаёт книги из «Книжной полки».
Репозиторий открытый — файлы отсюда может скачать любой. Закрытому репозиторию нужен токен в настройках экрана.
