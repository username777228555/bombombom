# Brainstorm 0.7: настоящие результаты, а не иллюзия обучения

Цель приложения: баллы на олимпиадах (ВсОШ, «Высшая проба», «Изумруд», РАНХиГС, РГГУ). Чтобы видеть движение,
нужны не очки опыта и ударный режим, а растущая доля верных ответов **через несколько дней** на задания **олимпиадного вида**.

## Что даёт результат (и чего не хватает)

| Принцип | Что это значит | Что есть | Чего нет |
|---|---|---|---|
| Вспоминание, а не узнавание | ответ своими словами важнее выбора из 4 вариантов | карточки, ввод года и термина | большинство вопросов — выбор из вариантов |
| Интервальное повторение | вернуться к материалу, когда он почти забыт | FSRS для карточек | ошибки в тестах не возвращаются по расписанию |
| Отложенная проверка | мерить знание через неделю, а не сразу | — | всё меряется сразу после изучения |
| Работа над слабым | больше времени на то, что не получается | «Работа над ошибками» | нет карты «что я знаю / не знаю» по эпохам и видам заданий |
| Перемешивание | эпохи и типы заданий вперемешку | тест дня | нет плана занятия |
| Олимпиадные форматы | источник, ряд, лишнее, атрибуция, развёрнутый ответ, эссе | развёрнутые ответы, пробники, картины | **нет хрестоматии источников**, рядов «что объединяет», «лишнего», вопросов «почему» |
| Историография | точки зрения историков — 8 баллов в эссе ВсОШ | пособие по эссе | нет историков и их концепций в базе |
| Честная самооценка | уверенность против точности | — | «угадал» засчитывается как «знаю» |

## Идеи

### Измерение
1. **Карта знаний**: эпохи × навыки (даты, личности, термины, культура, источники, причины). Доля верных ответов
   за последние 30 дней с поправкой на забывание. Отвечает на вопрос, что подтянуть, и одним нажатием запускает тренировку.
2. **Журнал ответов**: каждый ответ (сущность, эпоха, навык, балл, дата). Основа для карты, отложенных проверок и отчётов.
3. **Отложенная проверка**: вопросы, на которые ответил верно 3–30 дней назад, задаются снова. Удержание = доля верных повторно.
4. **Уверенность**: перед ответом «знаю / сомневаюсь / наугад». «Верно наугад» считается слабым местом.
5. **Готовность к олимпиаде**: результаты пробников по видам заданий и их динамика.

### Механика
6. **Ошибки по расписанию**: неверный ответ возвращается через 1, 3, 7, 21 день, пока не будет дважды верен.
7. **План на сегодня** вместо «опыта»: просроченные повторения + слабое место из карты + одно развёрнутое задание + новое.
8. **Сначала вспомни**: «не помню — покажи варианты» (балл уменьшается).
9. **«Почему?»** после верного ответа: короткий развёрнутый вопрос о причинах (из связей `cause`).
10. **Новые олимпиадные генераторы**: «что объединяет ряд» (участники одного события, деятели одной эпохи),
    «лишнее в ряду», «узнай источник по отрывку» (документ, автор, год, событие), «соотнеси источник и событие».
11. **Тренажёр эссе по шагам**: проблема → задачи → тезис+аргументы → точки зрения → вывод, с таймером и самопроверкой
    по критериям пособия; черновики сохраняются.

### Материалы
12. **Хрестоматия**: 150–250 отрывков ключевых источников (летописи, правды, судебники, уложения, манифесты, указы,
    договоры, речи, конституции, мемуары) с атрибуцией и подсказками. Только хорошо известные тексты, пересказ помечается.
13. **Историография**: историки (Татищев, Карамзин, Соловьёв, Ключевский, Платонов, Покровский, Зимин, Скрынников,
    Милов, Миронов…) и их концепции по ключевым сюжетам: основа для «точек зрения» в эссе.
14. **Пробники**: регулярно добавлять варианты с ключами (присылает владелец).
15. Больше культуры (архитектура, живопись) и всемирной истории для заданий на синхронизацию.

### Не делать
- Опыт за лёгкие повторы, ударный режим как цель, конфетти за 3 из 10.
- Вопросы, где ответ угадывается по формулировке или картинке.
- Рост числа материалов ради числа: каждый факт должен быть в олимпиадных заданиях или учебниках.

## Сделано в 0.7

- Журнал ответов, «Карта знаний» (эпохи × навыки, с поправкой на забывание), «План на сегодня» на главной.
- Ошибки по расписанию (1 → 3 → 7 дней) и отложенная проверка: треть верных ответов возвращается через неделю, «удержание» на карте.
- Повторения карточек тоже идут в карту.
- Хрестоматия: 271 отрывок источников (пересказ помечен), экран «Хрестоматия», вопросы «какой документ / год / автор / событие / по подсказкам».
- Форматы ВсОШ: «что объединяет ряд», «кто лишний», «лишнее понятие».
- Историография: 22 историка, 15 понятий, 8 тестов «кто что утверждал».
- Тренажёр эссе по схеме пособия: проверки по критериям, таймер, черновики.
- Быстрее на телефоне: галерея, термины, лента времени.

Осталось: уверенность при ответе («знаю / сомневаюсь / наугад»), «Почему?» после верного ответа, темы эссе (цитаты историков).

1. Журнал ответов → карта знаний → план на сегодня → ошибки по расписанию (код).

3. Уверенность и отложенная проверка, тренажёр эссе.
