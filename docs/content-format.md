# Формат контента СТОЛЫПИНЪ

Весь учебный контент — это **пакеты** в `content/packs/<id-пакета>/`. Приложение подхватывает их
автоматически: код менять не нужно. Схема (единственный источник правды) — `src/core/content/schema.ts`,
проверка — `pnpm content:check`.

```
content/
  core/periods.json          # периодизация (общая для всех пакетов)
  packs/
    osnova/                  # пакет
      pack.json              # манифест
      data/*.json            # фрагменты с данными (любые имена и вложенность)
      images/…               # картинки пакета (необязательно)
```

Файлы и папки, чьё имя начинается с `_` или `.`, считаются черновиками и игнорируются.

## Как добавить материалы (для людей и агентов)

1. Решите, куда класть: дополнение к существующей теме — новый файл в существующем пакете;
   отдельный курс/книга/набор — новый пакет: `pnpm content:new <id> "Название"`.
2. Создайте файл-фрагмент, например `content/packs/<пакет>/data/c18-kultura.json`. В одном файле
   можно хранить любые коллекции: `events`, `persons`, `culture`, `terms`, `links`, `sources`,
   `decks`, `quizzes`, `maps`.
3. Перед созданием новой персоналии/события найдите, нет ли его уже: `rg '"id": "p-petr-i"' content`
   или `rg 'Пётр I' content`. Ссылайтесь на существующие id, не дублируйте.
4. Проверьте файл: `pnpm content:check --file <путь>`, затем весь корпус: `pnpm content:check`.
   Ошибки (✖) обязательно исправить, предупреждения (⚠) — просмотреть.
5. Посмотрите статистику: `pnpm content:stats`.

## Идентификаторы

- Только `a-z`, `0-9` и дефисы. Уникальны во **всём** корпусе.
- Префикс по типу: событие `e-`, персоналия `p-`, памятник культуры `c-`, термин `t-`,
  источник `s-`, колода `d-`, тест `q-`, карта `m-`.
- Транслитерация: `а-a б-b в-v г-g д-d е/ё-e ж-zh з-z и-i й-y к-k л-l м-m н-n о-o п-p р-r с-s т-t у-u
  ф-f х-kh ц-ts ч-ch ш-sh щ-shch ъ/ь-(пропуск) ы-y э-e ю-yu я-ya`, римские цифры — латиницей.
  Готовый id выдаёт `pnpm content:id person "Иван III"` → `p-ivan-iii`.
- Персоналии: правители — `p-<имя>-<номер>` (`p-petr-i`, `p-ivan-iv`) или `p-<имя>-<прозвище>`
  (`p-yaroslav-mudryy`); остальные — `p-<фамилия>` (`p-stolypin`), при неоднозначности
  `p-<имя>-<фамилия>`.
- События — `e-<суть>[-<год>]`: `e-kreshchenie-rusi`, `e-poltavskaya-bitva`, `e-reforma-1861`.

## Общие поля и правила

- Язык — русский, орфография современная. Даты до н. э. — отрицательные числа.
- `summary` — 1–3 предложения: суть и значение. `details` — развёрнутый текст (абзацы через `\n\n`).
- `importance`: `3` — обязательно знать (школьный этап), `2` — важно, `1` — деталь для финала.
- `confidence`: `high` (по умолчанию) — уверены; `medium` — есть сомнения в дате/детали;
  `low` — спорно, нужно сверить. Приложение подсвечивает `medium`/`low`.
- `refs` — откуда взято: «Учебник Орлова, гл. 5», «Лекция МГУ №3», ссылка.
- Месяц и день (`month`, `day`) для событий до 1918 года — по старому стилю, как в учебниках.
- `circa: true` — дата приблизительная («около 862 г.»).
- Картинки: `image: "images/<файл>.webp"` (путь внутри пакета) или `https://…`. Не больше ~300 КБ,
  только с разрешённой лицензией; автора и лицензию укажите в `refs`.
- Длинные цитаты из современных книг класть нельзя (авторское право). Выжимки своими словами — можно.

## Коллекции

### events — события

```json
{
  "id": "e-kreshchenie-rusi",
  "title": "Крещение Руси",
  "year": 988,
  "period": "ancient",
  "tags": ["church", "politics"],
  "importance": 3,
  "summary": "Князь Владимир Святославич принял христианство по византийскому обряду и сделал его государственной религией.",
  "place": "Киев",
  "persons": ["p-vladimir-i"]
}
```

Обязательные: `id`, `title`, `year`, `period`, `summary`. Необязательные: `month`, `day`, `endYear`,
`endMonth`, `endDay`, `circa`, `scope` (`russia` | `world` — мировые события для синхронной ленты),
`tags`, `importance`, `details`, `place`, `persons` (id персоналий), `image`, `confidence`, `refs`.

Теги: `politics` политика, `war` война, `reform` реформа, `economy` экономика, `society` общество,
`church` церковь, `culture` культура, `foreign` внешняя политика, `uprising` восстание, `law` право,
`science` наука, `dynasty` династия, `territory` территория.

### persons — персоналии

```json
{
  "id": "p-vladimir-i",
  "name": "Владимир I Святославич",
  "short": "Владимир Святой",
  "aliases": ["Владимир Красное Солнышко", "Владимир Святославич"],
  "born": 960,
  "died": 1015,
  "circa": true,
  "periods": ["ancient"],
  "role": "Великий князь киевский",
  "reigns": [{ "title": "Великий князь киевский", "from": 978, "to": 1015 }],
  "tags": ["ruler"],
  "importance": 3,
  "summary": "Креститель Руси, строитель оборонительных «Змиевых валов», при нём сложилась система наместничества сыновей.",
  "hints": [
    "Был сыном князя и ключницы Малуши.",
    "Начинал с попытки создать единый языческий пантеон.",
    "Выбирал веру, отправляя послов в разные страны.",
    "Крестил Русь в 988 году."
  ]
}
```

Обязательные: `id`, `name`, `periods` (первый — основной), `role`, `summary`.
`born`/`died` — год или `null`. `reigns` — периоды пребывания на престоле/посту (для ленты правителей).
`hints` — 3–5 подсказок для игры «Кто я?»: от самой трудной к самой лёгкой, **без имени**.
Теги: `ruler`, `statesman`, `military`, `church`, `culture`, `science`, `revolutionary`, `reformer`,
`writer`, `artist`, `historian`, `diplomat`, `rebel`, `explorer`, `entrepreneur`.

### culture — памятники культуры

```json
{
  "id": "c-sofiya-kievskaya",
  "title": "Софийский собор в Киеве",
  "kind": "architecture",
  "period": "ancient",
  "year": 1037,
  "circa": true,
  "authors": [],
  "place": "Киев",
  "summary": "Главный храм Киевской Руси, построен при Ярославе Мудром.",
  "features": ["13 глав", "мозаики и фрески", "крестово-купольный храм"],
  "importance": 3
}
```

Обязательные: `id`, `title`, `kind`, `period`, `year`, `summary`. `authors` — id персоналий,
`authorName` — автор, если его нет среди персоналий. `features` — признаки для атрибуции.
Виды (`kind`): `architecture`, `icon`, `painting`, `literature`, `chronicle`, `sculpture`, `music`,
`theatre`, `cinema`, `science`, `applied`, `document`.

### terms — термины

```json
{ "id": "t-polyude", "term": "Полюдье", "definition": "Ежегодный объезд князем с дружиной подвластных земель для сбора дани.", "periods": ["ancient"], "related": ["e-vosstanie-drevlyan"] }
```

### links — связи (граф)

```json
{ "from": "e-vosstanie-drevlyan", "to": "e-reformy-olgi", "type": "cause" }
```

| type | Смысл | Направление |
|------|-------|-------------|
| `cause` | from привело к to | событие → событие |
| `part-of` | from — часть to | битва → война |
| `participant` | участвовал | персона → событие |
| `leader` | руководил, возглавлял | персона → событие |
| `author` | автор, создатель | персона → памятник/источник/реформа |
| `successor` | from наследовал to | персона → персона |
| `parent` | from — родитель to | персона → персона |
| `influence` | from повлиял на to | любое |
| `spouse`, `ally`, `opponent`, `related` | супруги, союзники, противники, связь | симметричные |

Связи «персона участвовала в событии» можно не дублировать: поле `persons` у события уже создаёт их.

### sources — исторические источники (атрибуция)

```json
{
  "id": "s-pvl-prizvanie",
  "title": "Повесть временных лет",
  "kind": "chronicle",
  "period": "ancient",
  "year": 862,
  "excerpt": "Земля наша велика и обильна, а порядка в ней нет. Приходите княжить и владеть нами.",
  "clues": ["призвание варягов", "летописная формула"],
  "note": "Легенда о призвании варягов, запись под 862 годом."
}
```

### decks — колоды карточек

Карточки по датам, персоналиям, терминам и памятникам приложение строит **само** из данных выше.
Колоды нужны для особых наборов (например, по конкретной лекции):

```json
{ "id": "d-lektsiya-3", "title": "Лекция 3: Смута", "period": "c17", "cards": [
  { "id": "k1", "front": "Семибоярщина", "back": "Правительство из семи бояр в 1610–1612 гг." }
] }
```

### quizzes — тесты

```json
{ "id": "q-ancient-osnova", "title": "Древняя Русь: основа", "period": "ancient", "level": "school", "questions": [ … ] }
```

Типы вопросов (у всех: `prompt`, необязательные `explain`, `excerpt` — отрывок источника, `image`, `points`):

| type | Поля | Пример |
|------|------|--------|
| `single` | `options[]`, `answer` (индекс с 0) | `{"type":"single","prompt":"Кто крестил Русь?","options":["Олег","Владимир I","Игорь"],"answer":1}` |
| `multiple` | `options[]`, `answers[]` | `{"type":"multiple","prompt":"Выберите реформы Петра I","options":["…"],"answers":[0,2]}` |
| `order` | `items[]` — **в правильном порядке** | `{"type":"order","prompt":"Расположите в хронологическом порядке","items":["Призвание варягов","Крещение Руси","Любечский съезд"]}` |
| `match` | `pairs[]` — `[левое, правое]` | `{"type":"match","prompt":"Соотнесите","pairs":[["988","Крещение Руси"],["1097","Любечский съезд"]]}` |
| `year` | `answer`, `tolerance` | `{"type":"year","prompt":"Год Ледового побоища","answer":1242}` |
| `text` | `answers[]` — допустимые варианты | `{"type":"text","prompt":"Как называлась дань в Орду?","answers":["выход","ордынский выход"]}` |
| `hints` | `hints[]`, `answers[]` | `{"type":"hints","hints":["…","…"],"answers":["Ярослав Мудрый"]}` |
| `errors` | `segments[]` с `wrong`/`fix` | `{"type":"errors","prompt":"Найдите ошибки","segments":[{"text":"В 1240 году "},{"text":"Дмитрий Донской","wrong":true,"fix":"Александр Невский"},{"text":" разбил шведов на Неве."}]}` |

### maps — карты

```json
{ "id": "m-rus-xi", "title": "Русь в XI веке", "period": "ancient", "image": "images/rus-xi.webp",
  "width": 1600, "height": 1200, "points": [{ "id": "kiev", "label": "Киев", "x": 812, "y": 904, "entity": "e-kreshchenie-rusi" }] }
```

`x`, `y` — пиксели исходного изображения.

## Пакет одним файлом

`pnpm content:bundle <id>` собирает `dist-packs/<id>.stolypin.json`. Такой файл можно импортировать
прямо в приложении (Профиль → Пакеты), не пересобирая APK. Удобно для личных материалов.

## JSON Schema

`pnpm content:schema` генерирует `content/schema/*.schema.json`. Добавьте в начало фрагмента
`"$schema": "../../../schema/fragment.schema.json"` — редактор начнёт подсказывать поля.
