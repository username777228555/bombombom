# Дизайн-система СТОЛЫПИНЪ

Настроение — «кабинет историка»: тёплая бумага, золото, бордо, старинный шрифт в заголовках, живопись
русских художников. Всё собрано из токенов и компонентов `src/design/`: в новых экранах не нужно
хардкодить цвета и размеры.

## Токены и темы

- `src/design/tokens.css` — шрифты (`--font-display` Old Standard TT, `--font-ui` Inter, `--font-read` Literata),
  размеры текста `--text-*`, отступы `--sp-*`, радиусы `--r-*`, кривые и длительности анимаций.
- `src/design/themes.css` — «Пергамент» (светлая) и «Ночь» (тёмная) + акценты `data-accent`.
  Цвета: `--bg`, `--surface(-2,-3)`, `--line`, `--ink(-2,-3)`, `--gold`, `--accent`, статусы `--success/danger/…`.
  `--glow` — тёплое свечение вверху экрана, `--shadow-1` — тень карточки с бликом «бумаги».
- `src/design/base.css` — сброс, типографика, `.page`, `.section-title` (золотой ромбик после заголовка),
  `.hscroll`, `.surface`, `.rise` (появление с задержкой `--i`).

## Компоненты (`src/design/components/`)

| Компонент | Для чего |
|-----------|----------|
| `Card`, `Tile`, `Button`, `Chip`, `Segmented`, `TextField`, `IconButton` | основа всех экранов |
| `PageHeader` | липкая шапка с «Назад» и действиями |
| `Ornament` | золотой разделитель; `variant="flourish"` — вязь с завитками. Рисуется при появлении |
| `Emblem` | монограмма «Съ»; `animate` — рисует рамку, проявляет буквы, пускает золотой блик |
| `Laurel` | лавровый венок (листья распускаются по очереди); внутрь кладётся иконка или число |
| `Painting` | картина в золотой раме с медленным «кен-бёрнсом»; `caption` — подпись на затемнении |
| `ProgressRing`, `ProgressBar`, `StatTile`, `Badge`, `Avatar`, `EmptyState` | статистика и мелочи |

Предметные компоненты лежат в `src/components/`: `EpochBanner` (шапка эпохи на картине-обложке периода),
`PeriodCard`, `EntityRow`, `EntityPreview`, вопросы тестов.

## Живопись

- Обложки эпох: `public/images/periods/<id>.webp` (общественное достояние: Васнецов, Суриков, Серов,
  Кившенко, Кустодиев) → `kb.periodCover(period)`. Используются в `PeriodCard`, `EpochBanner`, фоне героя на Главной.
- Иллюстрации событий: поле `image` у события в пакете → `kb.imageOf(entity)`. Из них автоматически собираются
  «Галерея», викторина «Что изображено?» и «Картина дня» на Главной.
- Новые картины: только общественное достояние или свободная лицензия, webp до ~300 КБ, автор и название — в `refs`.

## Анимации

- Любая анимация должна уважать «Меньше анимаций»: в JS — `motionOK()` из `core/settings.svelte`, в CSS —
  обычные `@keyframes` (глобальное правило в `base.css` укорачивает их до 1 мс при `data-motion="reduced"`).
- `src/design/motion.ts`:
  - `use:reveal={{ delay: i * 40 }}` — элемент плавно всплывает, когда появляется на экране (для списков и карточек);
  - `dailyPick(items, salt)` — стабильный выбор «на сегодня» (картина дня, фон героя).
- Переходы между экранами — `App.svelte` (`fly` по направлению навигации), листы — `SheetHost`.
- Длительности: 120–320 мс для отклика на нажатие, 500–700 мс для появления, 20+ с для «дыхания» картин.
  Пружина `--ease-spring` — для «наград» и индикаторов, `--ease-out` — для всего остального.

## Графика данных

- Лента времени (`modules/timeline`): подписи меряются по-настоящему (`textMeasure.svelte.ts`), ряды заполняются
  по важности (`pack.ts`), имена правителей обрезаются с многоточием по ширине плашки.
- Граф (`modules/graph`): раскладка fcose учитывает размеры подписей, `declutter.ts` раздвигает узлы и
  прячет подписи, которым не хватает места на текущем масштабе. Подписи держат экранный размер ~11–12 px.
- Проверка: `python3 scripts/qa/overlap_audit.py` — ноль пересечений.
