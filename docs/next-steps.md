Сделано в 0.5: по всем 11 периодам Sonnet пакетно дописал материалы (`content:brief` → `NN-<период>-plus.json` →
`content:check` → `content:merge`): событий 422 → 590, персоналий 285 → 349, терминов 175 → 282, связей 798 → 1308,
тестов 11 → 22 (у каждого периода второй тест олимпиадного уровня). Следующая порция — тем же способом
(`.agents/skills/add-content/BATCH.md`), волнами по 3–4 субагента, чтобы не упираться в лимит.

Осталось:

1. **Quizlet.** Конвейер готов и проверен на тестовом наборе (`scripts/quizlet/README.md`): `extract.py` разбирает
   PDF-распечатку или текстовый экспорт, `pnpm quizlet` сопоставляет карточки с базой и режет остальное на задания
   для Haiku/Sonnet. Ждём файл: PDF до 25 МБ — в `import/quizlet/`, больше — в релиз `import`. На реальной
   распечатке первым делом сверить числа карточек по наборам; если не сходятся — `--dump`/`--preview` и подстроить разбор.
2. **Проверка на телефоне.** Книга из релиза `books` (нативная загрузка), зум в Галерее, подсказки формата ответа,
   лента в 1982 году (один правитель).
3. **Связи `cause`/`part-of`.** Выборочная ревизия причинно-следственных связей, как сделано для `opponent`/`ally`.
4. **Публичная версия** (позже): убрать купленные книги из каталога «Книжной полки» и из `books/`; пакеты
   всемирной истории, античности, Китая — отдельными пакетами (`pnpm content:new`).
