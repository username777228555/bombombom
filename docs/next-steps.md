# Что дальше (план после v0.4.0)

Список задач для следующих сессий. Большинство — данные: подходит модель подешевле (Sonnet), код уже готов.

1. **Правители — данные** (Sonnet). Код для дат и коллективного правления готов, данных нет.
   - `fromDate`/`toDate` («ММ-ДД», до 1918 — ст. ст.) для всех переходных лет из `pnpm content:rulers`
     (1389 … 1982 Брежнев → Андропов … 2012).
   - Недостающие великие князья: 963, 973–979, 1133–1154, 1175, 1217, 1247–1251, 1264–1303, 1319–1327, 1341–1358.
   - Смута: Ф. И. Мстиславский (`kind: council`, `label: "Семибоярщина"`, 1610-07-17 … 1612-10-26),
     Д. Пожарский (`council`, `label: "Совет всея земли"`, 1612-10-26 … 1613-02-21).
   - Готово, когда `pnpm content:rulers` не показывает годов без правителя.
2. **Ревизия связей графа** (Sonnet/Haiku). Пройти все `opponent`/`ally` и `related` «правитель — памятник»,
   убрать натяжки (как было с Путиным и Зюгановым).
3. **Картинки с надписями** (модель с распознаванием изображений). Сетки миниатюр всех картинок событий, пометить
   `imageQuiz: false`, где надпись выдаёт ответ (например, фото «Делегаты XIV съезда ВКП(б)»).
4. **Quizlet**. Распечатку в PDF положить в репозиторий → текст → колоды `decks` в пакете, сверить с базой,
   дополнить старые карточки.
5. **Новые материалы** (новейшая история): Беслан и отмена выборов губернаторов (2004), Мюнхенская речь (2007),
   смена власти в Киеве (2014), персоналии. Картинки — коммит с `[media]` (по полю `wiki`).
6. **Проверка на телефоне** (v0.4.0): скачивание из релизов GitHub (нативный путь не проверен в браузере), зум
   в Галерее, подсказки формата ответа.
7. **Публичная версия** (позже): убрать купленные книги из каталога «Книжной полки»; пакеты всемирной истории,
   античности, Китая — отдельными пакетами (`pnpm content:new`).
