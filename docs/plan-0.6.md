   Пока их нет — «Олимпиадный вариант»: 12 тестовых и 4 развёрнутых задания из материалов приложения, с таймером.
   Для развёрнутых ответов (их в олимпиадах большинство) добавлен тип вопроса `open`: эталон + критерии, ученик сверяется сам;
   такие вопросы генерируются из базы (причины, последствия, деятельность) и есть тест «Развёрнутые ответы» в каждом периоде.
