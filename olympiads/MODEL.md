# Пробник из олимпиады: инструкция для модели

Ты переносишь в приложение один вариант олимпиады по истории: задания и официальные ключи.
Ответы берутся **только из ключей**, ничего не додумывай. Если для задания нет ответа в ключах, пропусти его.

## Что есть на входе

- текст заданий и текст ключей (`import/olympiads/txt/*.txt`, извлечены `pdftotext -layout`, бывают переносы и колонки).
  Если текст непонятен, отрисуй страницу: `pdftoppm -r 110 -f N -l N -png import/olympiads/<файл>.pdf /tmp/.../p` и посмотри картинку;
- картинки из заданий: `olympiads/src/<id>/pN-MM.jpg`, где N — номер страницы PDF с заданиями. Посмотри их инструментом Read,
  чтобы понять, к какому заданию какая относится.

## Что на выходе

Один файл `olympiads/src/<id>.json`:

```json
{"pack": {"id": "<id>", "title": "«Высшая проба» 2026, заключительный этап", "description": "11 класс. Задания и ключи олимпиады. 120 минут, 100 баллов.", "version": "1.0.0"},
 "quizzes": [{"id": "q-<id без olymp->", "title": "Вариант (11 класс)", "level": "final", "questions": [ … ]}]}
```

`level`: `school` — школьный или муниципальный этап, `region` — региональный или отборочный, `final` — заключительный.
Если в олимпиаде несколько туров или блоков, сделай по тесту на каждый.

## Как переносить задания

Задание из нескольких вопросов разбей на отдельные вопросы. Общий текст источника повторяй в `excerpt` каждого из них:
ученик видит источник при каждом вопросе. Длинный источник переноси целиком, без сокращений, абзацы через `\n`.

- Короткий ответ (имя, термин, событие, название) → `text`, в `answers` все формы, которые ключ засчитывает
  («Татищев», «В. Н. Татищев», «Василий Никитич Татищев»);
- год → `year`;
- выбор из списка → `single` или `multiple`;
- расставить по порядку → `order`, `items` в правильном порядке;
- соотнести → `match`, `pairs`;
- найти ошибки в тексте → `errors`;
- развёрнутый ответ (объяснить, сравнить, аргументировать, охарактеризовать) → `open`:
  `answer` — эталон из ключа (можно сжать, но без потери фактов), `criteria` — критерии оценивания из ключа,
  по одному проверяемому пункту на строку («Указано, что… — 2 балла»);
- задание с картинкой: `"image": "p3-02.jpg"` (имя файла из `olympiads/src/<id>/`);
- историческое сочинение или эссе не переноси: в приложении для него «Историческое эссе». Упомяни в `description`, что его нет.

У каждого вопроса: `prompt` (формулировка из олимпиады), `points` (баллы по ключу, если указаны), `explain` (1–3 предложения из ключа: почему так).
Всё по-русски, исправь артефакты распознавания (разорванные слова, лишние пробелы).

## Проверка

`pnpm -s olympiads <id>` — исправь каждую ✖. Он же соберёт `olympiads/<id>.stolypin.json`. Другие файлы не трогай.
