# Пробники олимпиад

Задания олимпиад прошлых лет (ВсОШ, Высшая проба, «Изумруд»…) для экрана
«Практика → Пробники». В APK они не встроены: приложение скачивает их отсюда по кнопке
и ставит как пакет, после чего тесты появляются в «Пробниках» и в «Тестах из материалов».

- `src/<id>.json` — исходник одного пробника (олимпиада, год, этап):
  ```json
  {"pack": {"id": "olymp-vsosh-2025-region", "title": "ВсОШ 2025, региональный этап", "description": "11 класс. Задания и ключи — с сайта олимпиады.", "version": "1.0.0"},
   "quizzes": [{"id": "q-vsosh-2025-region-1", "title": "Тур 1", "level": "region", "questions": [...]}]}
  ```
  id пакета начинается с `olymp-`. Вопросы — в формате тестов приложения (`docs/content-format.md`, раздел про тесты):
  `single`, `multiple`, `order`, `match`, `year`, `text`, `hints`, `errors`, `open` (развёрнутый ответ: эталон `answer` и `criteria` — что проверяющий ищет в ответе; ученик сверяется сам). У любого может быть `excerpt` — отрывок источника и `points` — баллы по ключу.
- `pnpm olympiads` — проверка и сборка: `src/<id>.json` → `<id>.stolypin.json` (их и видит приложение).
  `pnpm olympiads --check` — только проверка.

Задания берутся только из присланных владельцем файлов с ключами: ответы не додумываются.
Развёрнутые ответы — тип `open`: эталон и критерии берутся из ключей и критериев оценивания олимпиады.
Эссе — не сюда (для него «Историческое эссе»), работа с картой без картинки пропускается.
